# Lakewood Conference Centre Website

A responsive website for **Lakewood Conference Centre**, showcasing its venue, facilities, events, gallery and contact information.

## Live Website

**Visit the website:**  
https://zameermia78-spec.github.io/lakewood-conference-centre-pages/

## Project Overview

The Lakewood Conference Centre website was developed as part of the WEDE5020 web development project. The website provides visitors with information about the venue and allows potential clients to explore its facilities and make enquiries.

## Features

- Responsive navigation for desktop, tablet and mobile devices.
- Homepage introducing Lakewood Conference Centre.
- Venue information and facilities.
- Interactive image gallery with category filters.
- Gallery search functionality.
- Image lightbox with captions and previous/next navigation.
- Event enquiry form with a review summary.
- Contact form with input validation.
- Interactive location map.
- Search engine optimisation (SEO) metadata.
- Open Graph metadata for social sharing.
- Sitemap and robots.txt files.
- Custom 404 error page.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Leaflet
- OpenStreetMap
- GitHub
- GitHub Pages

## Running the Website Locally

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Navigate through the website and test its features.

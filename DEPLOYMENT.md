# Deployment checklist

This project is currently a local static-site package. No deployment has been performed.

1. Confirm the assigned public Part 3 repository and its default branch.
2. Copy the contents of this folder into that repository, retaining paths.
3. Enable GitHub Pages (Settings → Pages → Deploy from a branch → main → /(root)), or use the host specified by the lecturer.
4. After the public URL exists, replace `YOUR-DEPLOYED-DOMAIN` in `index.html`, `robots.txt` and `sitemap.xml` with the exact HTTPS URL.
5. Test the live homepage, internal navigation, scripts, images, form validation, print summary, contact mailto, map, and 404 route.
6. Add the live URL and deployment screenshot to `README.md`.

Do not invent a deployment URL. Do not treat the `mailto:` contact form or the client-side enquiry summary as server-side submission. The enquiry summary is a front-end demonstration until a secure backend or approved form service is configured.
